# Reproduce on HW-001 (Acer Nitro AN515-51)

1. Boot Linux Mint 22.3 (or note distro delta).
2. Confirm sink: `alsa_output.pci-0000_00_1f.3.analog-stereo` (ALC255) unless testing HDMI.
3. `pactl info` → PipeWire · 48000 Hz.
4. Flatpak EasyEffects 8.x running.
5. From repo root:

```bash
./scripts/install.sh --flatpak
flatpak run com.github.wwmm.easyeffects -l <preset>
```
