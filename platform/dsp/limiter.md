# When to use a limiter

## Role

A limiter is a **safety ceiling**, not a loudness weapon. In this platform every loud
chain ends with a limiter so Bass Enhancer / Exciter / Autogain cannot hard-clip the sink.

## Use when

- Any enhancer increases crest factor unpredictably
- Autogain is in the chain
- Laptop speakers with weak headroom

## Avoid misuse

- Driving threshold so hard that the limiter is always active (pumping, fatigue)
- Using limiter alone as a “volume booster” (`volume-booster-01` still needs care)
