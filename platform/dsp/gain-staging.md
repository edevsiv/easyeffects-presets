# Gain staging in EasyEffects chains

Typical order for heavy chains:

```text
Autogain → dynamics → EQ → exciters/bass → stereo → Limiter
```

Rules of thumb:

1. Fix level early (Autogain) without slamming later stages
2. EQ cuts preferred over boosts when correcting
3. Enhancers last before limiter
4. Limiter threshold leaves a few dB of idle headroom on calm content
