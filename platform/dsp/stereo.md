# How to calibrate stereo

## Tools

EasyEffects **Stereo Tools** (width, side gain, balance).

## Guidelines

- Start near default width; small increments
- Watch for mid collapse or unstable mono compatibility
- Gaming: prioritize localization over “huge” width
- Music: width should not create listener fatigue at 30+ minutes

## Calibration loop

1. Flat reference → note image
2. Enable Stereo Tools only → A/B
3. Re-introduce EQ/enhancers
4. Document in listening form (Stereo score)

See [docs/audio-engine/StereoTools.md](../../docs/audio-engine/StereoTools.md).
