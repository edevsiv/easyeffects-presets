# How to use AutoEQ

1. Obtain ParametricEQ.txt for your headphones (AutoEQ / measurements)
2. Import via EasyEffects Equalizer APO
3. Confirm preamp / negative gain
4. Apply a **content** profile carefully — avoid stacking smile curves
5. Generate a Markdown recommendation with `autoeq/recommend.py` (does not edit presets)
