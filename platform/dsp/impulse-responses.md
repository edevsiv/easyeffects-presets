# How to use impulse responses (IR)

1. Select IR via [OFFICIAL_IR.md](../../impulse-responses/OFFICIAL_IR.md) / catalog scorecard
2. Confirm license allows your use case
3. Resample if needed
4. Load in Convolver; bypass other spatial wideners initially
5. A/B vs Flat; log latency and Fatigue
