# Calibration × profile matrix (starter)

| Hardware class | First profile | Avoid initially | Notes |
|----------------|---------------|-----------------|-------|
| Notebook speakers / ALC255 | `cinema-01`, `voice-boost-01` | `fxsound-ultimate-02` | Fatigue + harsh treble risk |
| Headphones (unknown FR) | `music-hd-01` + AutoEQ | Stacking smile EQ + AutoEQ | Use recommend.py |
| Gaming headset | `gaming-01` | Heavy `*-02` in competitive | Prefer clarity |
| USB DAC | `music-hd-01`, `classic-music-01` | Extreme bass enhancer | Let DAC do loudness |
| Bluetooth | lighter `*-01` | Long convolvers | Codec + latency |
| Speakers 2.1 | `cinema-02` (careful), `music-hd-02` | Over-boosted LFE feel | Check sub integration |
| HDMI (GPU) | content `*-01` | Assuming bitperfect passthrough | Need PCM path |

Update after listening evidence — do not treat as certified.
