# Hardware schema

| Field | Description |
|-------|-------------|
| `id` | `HW-XXX` |
| `manufacturer` / `model` | Device identity |
| `classes` | Tags from platform taxonomy |
| `chipset` | e.g. ALC255 |
| `sink_type` | Speakers / headphones / HDMI / BT / DAC |
| `pipewire_notes` | Rate, quantum, quirks |
| `easyeffects_notes` | Flatpak/native path, known plugin issues |
| `scorecard` | Link to scored evaluation |
| `recommended_profiles` | Profile IDs |
| `evidence` | Paths under `validation/` |
