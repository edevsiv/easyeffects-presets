# Hardware scorecard system

Each registered device SHOULD be scored 1–5 on:

| Dimension | Meaning |
|-----------|---------|
| **Compatibility** | Loads EE presets cleanly; stable PW graph |
| **Quality** | Subjective/objective fidelity on this endpoint |
| **Known problems** | Documented issues (count + severity narrative) |
| **Preset fit** | How well recommended profiles match the device |
| **Notes** | Free-form engineering notes |

## Aggregation

- Do **not** average across incompatible classes (BT ≠ wired DAC).
- Prefer P0 reference hardware for seal promotions.
- Unknown dimensions stay blank — never invent scores.
