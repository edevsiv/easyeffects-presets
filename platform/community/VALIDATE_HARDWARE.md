# How to validate hardware

1. Create `HW-XXX` sheet under `validation/hardware/`
2. Tag classes in `platform/hardware/<class>/`
3. Fill [SCORECARD_TEMPLATE.md](../hardware/SCORECARD_TEMPLATE.md) → `scorecards/`
4. Capture EE load evidence (screenshot or ui-load log)
5. Optionally run listening session
6. Link from calibration matrix if recommendations change
