# Movie / series references

| Title (examples) | Why |
|------------------|-----|
| Dialogue-heavy dramas (e.g. courtroom / interview-driven series) | Tests voice intelligibility vs music beds |
| Modern action blockbusters with big LFE | Tests bass enhancer + limiter behaviour on explosions |
| Sci-fi with dense sound design | Tests multiband density and fatigue |
| Animated features with wide dynamic swings | Tests autogain pumping vs natural swings |
| Foreign-language films with subtle ADR | Tests presence EQ without sibilance |

**YouTube:** official trailers in stereo are useful for quick A/B but are already loudness-normalized — pair with locally stored films when possible.

**Preset focus:** `cinema-01`, `cinema-02`, `voice-boost-01`.
