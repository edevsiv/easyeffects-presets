# Objective measurements

Store meter readings, RTA screenshots notes, LUFS estimates, and crest-factor observations.

## Minimum objective checklist (when tools available)

| Measure | Tool examples | Notes |
|---------|---------------|-------|
| Integrated / short-term LUFS | EasyEffects level / external meter | Compare Autogain target adherence |
| True peak | Limiter GR meters | Confirm ceiling policy |
| Band energy (bass/presence/air) | Spectrum in EE | Before/after EQ |
| Stereo correlation | Correlation meter if available | Width sanity |

Until hardware metering is attached, mark datasheet evidence as `design-audit` only.
