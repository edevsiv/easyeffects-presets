# Release notes — v1.0.0

**Title:** EasyEffects Audio Platform — Public Stable

**Date:** 2026-08-02

## Highlights

- First **public Stable** release of the EasyEffects Audio Platform
- Official listening campaign **VC-2026-08-LISTEN** completed (11 sessions on HW-001)
- **9** profiles promoted Beta → Validated → **Stable**
- Platform layer (`platform/`), certification lab, install scripts, CI
- Flatpak install path fixed for EasyEffects 8.x (`data/easyeffects/output`)

## Install

```bash
git clone https://github.com/edevsiv/easyeffects-presets.git
cd easyeffects-presets
git checkout v1.0.0
./scripts/install.sh --flatpak   # or --native
```

Or download the presets ZIP from the GitHub Release assets and import in EasyEffects.
