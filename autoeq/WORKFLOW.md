# AutoEQ user workflow

1. Identify headphones / IEM
2. Export ParametricEQ.txt from AutoEQ
3. `python3 autoeq/recommend.py file.txt --headphone NAME -o recommendations/…`
4. Import APO in EasyEffects
5. Choose content profile via [platform/tools/recommend-by-hardware.md](../platform/tools/recommend-by-hardware.md)
6. Log session if contributing evidence
