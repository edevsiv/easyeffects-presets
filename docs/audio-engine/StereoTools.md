# Stereo Tools

Part of the [audio engine handbook](README.md).

## Function

Controls stereo image: width, balance, mute/swap, soft mid/side style adjustments (plugin-dependent).

## Advantages

- Stage width without full HRTF virtualization
- Useful gaming/music immersion knob

## Disadvantages

- Phasey/unstable mono compatibility
- Over-width collapses center dialog

## When to use

Music HD, gaming immersion, FxSound Surround approximations.

## When to avoid

Critical mono-summed PA; dialog-centric cinema if center collapses.

## Practical examples

- Slight width increase for music
- Prefer EQ for “space” before extreme widening
