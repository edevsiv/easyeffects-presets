# Compressor

Part of the [audio engine handbook](README.md).

## Function

Reduces dynamic range above a threshold with ratio/attack/release controls.

## Advantages

- Levels dialog and music beds
- Adds punch/glue
- Supports sidechain workflows in advanced setups

## Disadvantages

- Pumping if release/attack wrong
- Can kill musical dynamics
- Broadband comp can dull transients

## When to use

Voice presets, light music glue, gaming transient control before limiter.

## When to avoid

Critical classical listening; already hyper-compressed streaming masters (use lighter settings).

## Practical examples

- Voice: moderate ratio, medium attack, avoid breathing artefacts
- Gaming: faster attack on peaks, leave body intact
