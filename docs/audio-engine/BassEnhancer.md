# Bass Enhancer

Part of the [audio engine handbook](README.md).

## Function

Adds perceived low end, often via harmonics (MaxxBass-like psychoacoustics) and/or sub emphasis.

## Advantages

- Small speakers gain “bass” without impossible excursion
- Exciting for EDM/cinema LFE feel on headphones

## Disadvantages

- Mud, boom, intermodulation
- Masks kick/bass definition
- Dangerous without limiter

## When to use

Cinema, gaming immersion, FxSound-like experimental presets, weak laptop speakers.

## When to avoid

Bass-heavy tracks on capable headphones already at Harman-like targets; classical purity goals.

## Practical examples

- Start low; A/B with bass-heavy reference tracks
- High-pass mud region with EQ if needed
